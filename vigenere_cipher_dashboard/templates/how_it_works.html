How It Works

Understanding the Vigenère cipher from the ground up

What is the Vigenère Cipher?

The Vigenère Cipher is a polyalphabetic substitution cipher that uses a repeating keyword to encrypt text. Unlike the Caesar cipher, which shifts every letter by the same amount, the Vigenère cipher uses many different shift alphabets — one letter of the key chooses one shift, the next letter of the message uses the next letter of the key, and so on.

The key is repeated until it matches the length of the message, so a short keyword like KEY becomes KEYKEYKEY… while encrypting. Each letter is converted to a number (A = 0 … Z = 25), the formula is applied, and the result is wrapped around with mod 26 back into a letter.

Encryption
C = (P + K) mod 26
  • P = numeric value of the plaintext letter
  • K = numeric value of the key letter
  • C = numeric value of the ciphertext letter
Decryption
P = (C - K + 26) mod 26
  • The subtraction is reversed
  • + 26 prevents a negative result
  • mod 26 wraps the value back into A–Z

Spaces and special characters are copied through unchanged and do not consume a key character: HELLO WORLD with key KEY uses the repeated key KEYKEY KEYK.
Advantages
  • Uses multiple substitution alphabets
  • More secure than the Caesar cipher
  • Easy to understand
  • Simple to implement
  • Useful for learning cryptography
Limitations
  • Vulnerable to cryptanalysis
  • Repeating keys can reveal patterns
  • Short keys are easier to attack
  • Not suitable for modern secure communication
